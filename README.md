# Kuicko Restaurant Detail

A Flutter restaurant/store detail screen with a Talabat-inspired food delivery
layout and BLoC-managed interactions. Menu/store content is local sample data;
food and restaurant photos load from Unsplash and display placeholders when
offline.

## Features

- Restaurant hero, delivery details, offer card, menu search and category chips.
- Menu item quantity controls, live basket count and total.
- Favorite toggle and share feedback.
- Feature-first separation for store data, BLoC state/events, and presentation.

## Run

```sh
flutter pub get
flutter run
```

## Verify

```sh
flutter test
flutter analyze
```
